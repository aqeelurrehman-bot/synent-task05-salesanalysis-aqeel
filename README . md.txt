# Synent Internship Task 5 - Sales Data Analysis

Problem Statement
The purpose of this project is to analyze sales data and identify important business insights such as revenue trends, top-selling products, and profit performance.

Dataset Used
Superstore Sales Dataset

Objective
- Analyze monthly sales trends  
- Identify top-selling products  
- Perform profit analysis  
- Generate business insights  

 Tools Used
- Python  
- Pandas  
- Matplotlib  
- Visual Studio Code  

 Steps Performed
1. Loaded the sales dataset  
2. Converted date columns into proper format  
3. Calculated monthly revenue  
4. Identified top-selling products  
5. Visualized sales trends using charts  

 Results
Useful insights were generated to understand business performance.
